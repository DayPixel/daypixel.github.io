macOS

Apple Silicon (M1 이상)
macOS 14 이상

Mac용 다운로드 DMG · 3.7 MB
Mac 설치 방법
  1. 기존 버전이 있다면 먼저 종료하고 이전 앱을 휴지통으로 옮겨요. 프로필과 방 정보는 그대로 남아요.
  2. DMG를 열고 포프를 응용 프로그램 폴더로 옮겨요.
  3. 응용 프로그램 폴더에서 포프를 실행해요. 처음 실행할 때 확인 창이 나오면 ‘열기’를 선택해요.

Intel Mac용 빌드는 아직 제공하지 않아요.

Windows

Windows 10 22H2 / Windows 11
64비트 (x64)

Windows용 다운로드 EXE · 82.2 MB
Windows 설치 방법
  1. 다운로드한 Setup.exe를 실행하면 포프가 설치돼요.
  2. 다음부터는 시작 메뉴에서 포프를 열면 돼요.
  3. 작업 표시줄의 숨겨진 아이콘(∧)에서 포프 메뉴를 찾을 수 있어요.

추가 프로그램 설치는 필요하지 않아요.

자주 묻는 질문

Mac과 Windows끼리도 같이 쓸 수 있나요?

Mac과 Windows에서 같은 방에 들어가 서로 손을 흔들고 짧은 말을 주고받을 수 있어요. 일부 기능과 움직임은 운영체제에 따라 달라요.

내 화면이나 입력한 내용을 다른 사람이 볼 수 있나요?

화면 내용, 창 제목, 키보드 입력 내용은 보내지 않아요. 이름·하는 일·외형·활동 상태와 직접 보낸 인사·메시지를 공유해요. 친구 방 정보는 광장에 알리지 않고, 말하기는 현재 친구 방에서만 보여요.

방과 참가 목록은 서버에 저장해요. 앱은 접속 상태·인사·메시지를 대화 기록으로 저장하지 않아요. 프로필과 로그인 정보는 내 기기에 보관해요.

앱 언어는 어떻게 바꾸나요?

기본적으로 시스템 언어에 맞춰 시작해요. Mac은 메뉴의 설정 → Language / 언어에서, Windows는 트레이 메뉴의 언어에서 한국어·영어를 선택할 수 있어요. 같은 메뉴에서 시스템 언어 설정으로 돌아갈 수 있어요.

업데이트는 어떻게 하나요?

새 버전이 나오면 앱에서 알려드려요. 알림에서 설치를 선택하거나, 메뉴의 ‘업데이트 확인’을 눌러주세요.

0.2.0 사용자와 Windows ZIP 사용자는 위 설치 파일로 직접 설치해 주세요. Windows는 EXE로 설치하면 다음부터 앱에서 업데이트할 수 있어요.

작업에 방해가 되지는 않나요?

포프가 없는 곳의 클릭은 원래 앱으로 전달해요. 트레이·메뉴바에서 방해 금지, 잠시 숨기기, 투명도를 설정할 수 있어요. 전체화면 앱에서는 기본적으로 숨겨져요.
