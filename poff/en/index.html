Install on Mac
  1. If you have an older version, quit it and move the old app to the Trash. Your profile and saved rooms stay on your computer.
  2. Open the DMG and drag Poff into your Applications folder.
  3. Launch Poff from Applications. If macOS asks you to confirm on first launch, choose Open.

  1. Run the downloaded Setup.exe to install Poff.
  2. After installation, open Poff from the Start menu.
  3. Find the Poff menu in the taskbar’s hidden icons (∧).

No extra software is required. The Windows installer is not yet code-signed, and testing on a real Windows device is still pending.

Questions?

Can Mac and Windows users share a room?

Mac and Windows can join the same room, wave and exchange short messages. Features and movement differ by platform. Windows does not yet include automatic work detection, work statistics or stretch reminders, and some movement effects are Mac-only. Testing between real Mac and Windows devices is still pending.

Can others see my screen or what I type?

Poff does not send screen content, window titles or what you type. It shares your name, task, appearance, activity status and the waves and messages you choose to send. Private room details are not announced in the plaza, and messages are shown only in your current private room.

Rooms and membership lists are stored on the server. The app does not store presence, waves or messages as chat history. Your profile and sign-in information are kept on your device.

How do I switch languages?

Poff follows your system language by default. To choose English or Korean, open Settings → Language on Mac, or Language in the Windows tray menu. You can switch back to the system setting from the same menu.

How do updates work?

Poff can notify you when an update is available. Choose Install in the notification, or use Check for Updates in the app menu.

Version 0.2.0 users and Windows portable ZIP users should install the DMG or EXE above. Later updates are available in the installed app; the Windows portable ZIP does not include installer updates.

Will Poff get in the way?

Clicks outside Poff go through to the app underneath. Use the tray or menu bar to enable Do Not Disturb, hide Poff temporarily or adjust opacity. Poff is hidden in full-screen apps by default.
